Phase 5 decisions — v1.0 scope-locked

What this prototype commits to. Each card above respects all of the below.

D1 · Anatomy
4 zones, fixed order
Media → Core → Premium → Personalization. Premium collapses when absent; the other three are always present.
D2 · Polymorphism
One row, two content modes
Personalization row is narrative (states 2–6, 10), icon-only (state 7), or property-derived (states 1, 8). Never combined.
D3 · Explainability
"Why" caption always visible
Every personalized signal carries a small explainer underneath. No hover-to-reveal.
D4 · Inventory removal
Time on Zillow demoted
Removed as a media-zone badge. Where relevant, surfaces in the Personalization row's freshness slot (e.g., state 1: "18 days on market").
D5 · Quality gates
Presence · Reliability · Specificity · Freshness
Every signal must clear all four gates to qualify for the row. If a signal fails any gate, it falls through to the next in the priority chain.
PresenceReliabilitySpecificityFreshness
D6 · No competition
One item per zone
Zone 3 hosts Showcase OR BuyAbility, never both. Zone 4 hosts a single signal — even when several would qualify, the priority chain picks one.
D7 · Tone
Factual, numeric, never flowery
"Stays under your $2,000 budget" not "perfect for you." "22 min drive" not "easy commute." Numbers do the persuading.
D8 · Premium expression
Showcase + BuyAbility share zone 3
Both occupy the same slot but use distinct treatments — Showcase = listing-paid elevation (dark/gold), BuyAbility = fit-derived (Blue600 mark + meter). Never coexist.
D9 · Voyager handoff
Active-aware adds, doesn't replace
Voyager-landing layers a Purple500 eyebrow + left rail on top of standard personalization. Anatomy unchanged. Still one signal per zone.
D10 · Cross-LOB
Same anatomy, swapped content
For Sale uses the same 4-zone structure. BuyAbility lives in zone 3 (FS). Lease/Eligibility (FR) maps to pre-approval/financing (FS). Inline comments in source mark divergence points.
D11 · Mobile-first
~375px reference width
All density and truncation tuned for mobile. Wider viewports inherit the same card; only spacing scales.
D12 · ZxD adherence
Object Sans Heavy headings · 12px radius · soft elevation
Brand blue is reserved for action. Surfaces stay white over a neutral page. Showcase is the only dark moment. Pills are fully rounded. No light-colored backgrounds anywhere.
D13 · Price collocation
All price-related signals live with the price
Previous rent renders inline with current rent as a strike-through (Airbnb pattern). Frees the Personalization row from carrying price-cut as a freshness signal. Future hook for "1 month free" / concession chips in the same row.
